# Japanese Novel Open Source Organization

[公式サイト](https://jpnov.com)

小説を書くことに、もっと集中できるツールを。

新人賞、文学賞、小説賞などへの応募を目指す作者のために、日本語の小説執筆を支えるオープンソースのツールを開発しています。

無料で使いやすく、執筆の邪魔をしないことを大切にしています。執筆支援に AI は使わず、原稿は作者の手元のままになります。

## Japanese Novel ([vscode-jpnov][vscode-jpnov]) 

縦書きプレビュー、文章校正、応募原稿の整形や出力を支える [VS Code 拡張機能][vscode-jpnov-marketplace]です。

不具合の報告、機能の提案、開発への参加を歓迎します。
